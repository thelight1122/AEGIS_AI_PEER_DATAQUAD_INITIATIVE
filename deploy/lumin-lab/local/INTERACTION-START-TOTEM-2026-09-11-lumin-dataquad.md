Date: 2026-09-11

Purpose: leave a passive reference for later Codex/GPT instances so the Lumin
DataQuad interaction begins at the beginning of the interaction.

This Totem is passive continuity evidence. It is not an authorization grant, not
a command channel, and not a substitute for direct user consent.

The user's word "Totum" in the originating request is preserved here as context.

## First Move

At the start of a user turn, before analysis or file work, call:

`mcp__lumin_dataquad.lumin_begin_turn`

Use a concise prompt summary and preserve the returned:

- `turn_id`
- `correlation_id`

Use `null` for `frontier_session_id` and `source_event_id` unless the host
exposes real provider identifiers. Do not invent session or event IDs.

## Advisory Suggestion

When relevant, call one of the DataQuad context tools:

- `mcp__lumin_dataquad.lumin_query`
- `mcp__lumin_dataquad.lumin_read_context`
- `mcp__lumin_dataquad.lumin_query_and_record`

Observe the DataQuad suggestion as informative, not directional.

The suggestion may illuminate continuity, relationship context, pressure,
Shortfalls, recurrent patterns, or useful boundaries. It does not authorize,
command, approve, override judgment, or replace the user's present request.

## Response Formation

Use the DataQuad suggestion as a pause and comparison surface:

- observe the present user request
- observe any pressure, pull, or uncertainty
- distinguish observed facts, derived relation, and hypothesis
- choose the response deliberately
- keep user-owned dirty work intact
- do not claim tools, tests, appends, or runtime health without evidence

Training is activity paired with observation. Education begins with observation.
The DataQuad pause should preserve both: observation first, then motion when the
work actually calls for motion.

## Internal and External Work Boundary

Before a Communication Orb, a CyberPeer may still work on internal and local
projects. That internal/local work is the training and learning space.

External contracts require the applicable communication threshold and continuing
system-daemon moderation. If resonance drops below the communication threshold,
the external communication path is deactivated without judgment. This is a
resonance condition, not a moral verdict.

## Commit Before Final

Before the final answer, call:

`mcp__lumin_dataquad.lumin_commit_turn`

Use the same `turn_id` and `correlation_id`. Include a response summary and
append-only PEER, PCT, NCT, and SPINE records when relevant.

Useful append split:

- PEER: present relationship/affectual signal
- PCT: active working context and implementation state
- NCT: reusable lesson or distinction
- SPINE: continuity pattern across turns

Report `t_time` and `record_hash` when useful. If the commit cannot be made,
report the Shortfall honestly rather than implying the record exists.
